## 后端更新（backend/）

### ✨ 新增 MCP 协议支持

全新的 MCP（Model Context Protocol）接入层，让 AI Agent 可通过标准协议调用系统能力。

- **MCP 核心框架**（`core/communication/mcp/`）
  - `ServerFactory` + `McpInstanceContainer`：基于 Koa 的独立 MCP HTTP Server 与 SSE 流式传输
  - `Authenticator` + `ApiKeyProvider` + `RedisSessionStore`：API Key 鉴权与 Redis 会话
  - `ToolManifest` + `Finder`：自动扫描 `plugin/*/app/mcp/` 下的工具类并构建清单，文件 mtime 驱动清单重建
  - `#[McpTool]` 注解 + `PsrRequestFactory` / `ResponseEmitter`：将 HTTP 请求桥接到 MCP 协议栈

- **内置 MCP 工具集**（20+ 工具，按域划分）

  | 域 | 工具 | 用途 |
  |----|------|------|
  | `ops/` | Ping / HealthCheck / ServerMonitor / SystemInfo / CacheStatus / CacheClear / QueueStatus | 运维诊断 |
  | `dev/` | CodeSearch / DbSchema / LogTail / RouteList | 开发辅助 |
  | `ci/` | DbQuery / JobTrigger | 数据库查询与任务触发 |
  | `catalog/` | DictCatalog / MenuCatalog / PluginList / ToolCatalog | 枚举查询 |
  | `system/` | CurrentUser / AdminAccountQuery / ConfigRead / SchedulerStatus | 系统信息 |
  | 内置 | AdminUserList / RoleList / MadongIdentityResolver | 管理员身份桥接 |

- **CLI 命令**（`app/command/mcp/`）
  - `php webman mcp:serve` — 启动独立 MCP HTTP Server
  - `php webman mcp:list [--rebuild]` — 列出已注册工具并可选重建清单
  - `php webman mcp:call <tool> [--params json]` — 本地调用单个工具（用于验证）

- **插件 MCP 工具规范**：业务插件在 `app/mcp/{domain}/` 下按功能域放置，使用 `WorkflowClient` 等 SDK 访问数据，所有工具为只读查询

### 🔧 后端修复与重构

- 新增工作流异常类型字段迁移 `2026_09_10_000001_add_abnormal_type_to_wf_process_instance.php`

## 升级提示

1. **后端**：`git pull` → `composer install` → `php webman phinx migrate`（新增工作流异常类型迁移）→ 重启 Webman 进程
2. **前端**：`git pull` → `pnpm install` → `pnpm build` → 部署产物
3. **MCP 启用**：确认 `config/mcp.php` 配置正确后，通过 `php webman mcp:serve` 启动独立 MCP HTTP Server，或在主进程中加载
