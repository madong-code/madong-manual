## 🧩 backend（后端服务）

### 安全修复：导出下载路径遍历（CWE-22）

- `FilesController::downloadExcel()` 接入 `UploadDownloadExcelRequest` 请求 DTO，只取白名单字段，不再把 `$request->all()` 的内容直接拼到 `runtime_path()`；非法路径统一返回「非法的导出文件路径」，且不回显绝对路径。
- 新增 `core/io/excel/ExportPathGuard` 作为控制器与队列共用的唯一守卫：路径归一化、拒绝 `..`/绝对路径/控制字符、限定 `runtime/exports/` 下的 `.xlsx` 相对路径，`realpath()` 后按带目录分隔符的根前缀比较（防 `/exports-evil` 前缀绕过与符号链接逃逸）。
- `RemoveExcelFile` 队列消费者独立调用同一守卫，队列消息改为字段白名单（仅投递已校验的相对文件名），阻断任意文件删除与队列消息注入路径。
- `ExcelExportService` 复用守卫过滤下载响应名与磁盘文件名（路径符、CRLF、`..` 及 `& = # %` 等会污染 URL 查询串的字符），下载链接参数改用 `http_build_query(..., PHP_QUERY_RFC3986)` 编码。

### 安全修复：JWT 硬编码回退密钥（CWE-321 / CWE-798）

- `core/security/config/jwt.php` 不再提供示例默认密钥；`JwtToken` 构造移除公开固定密钥 `default-secret-key-for-development` 回退，密钥缺失、为占位值或短于 32 字符时直接 fail-fast。
- 新增 `core/security/jwt/JwtSecret` 作为密钥生成与校验唯一入口：256 bit 随机密钥、强度校验与 `.env` 幂等写入；安装器三条写 `.env` 路径统一生成随机密钥，重装时保留已有合法密钥。
- 新增 `php webman jwt:secret` 命令用于存量部署生成或轮换密钥（`--force` 强制轮换），密钥明文不输出。
- `.example.env` 移除固定示例密钥，空 `JWT_SECRET=` 置于模板末尾并补充醒目说明；补齐空 `APP_EVENT_LOOP=` 保持模板一致。

### 后台鉴权加固

- `adminapi/AccessTokenMiddleware` 改用 `JwtToken::getVerifiedPayload()`：在签名与过期校验之外叠加黑名单 JTI、令牌类型、用户标识与 Redis 中 JTI 注册复核，不再直接信任 `getPayloadFromRequest()` 中的身份声明；沿用现有 401/403 与 SSE 异常分支。
- `AdminValidate` 条件化 `not_in:root`：允许编辑安装期创建的既有 `root` 账号，仍禁止新建账号或把其他账号改名为 `root`。

### 安装服务与命令行（install / CLI）

- `InstallService`：前端构建失败降级为警告并继续写 `.env` 与安装锁；环境检测从 `.example.env` 创建 `.env` 并立即生成随机密钥，不再留下 0 字节空文件；`Util::reloadWebman()` 仅在 Worker 环境执行；移除 `checkInstalled()` 调试输出；保留标准版 `publishFrontendAssets()` 静态资源兜底。
- `BaseCommand`：新增 `runtime_error` SSE 分支返回非零退出码；密码输入统一改为 `fgets(STDIN)` 按行读取，消除 Windows CRLF 下与 Symfony 交互流混用导致的提问被跳过、答案错位。
- `InstallCommand`：`--build-project` 默认关闭且构建失败不阻断安装，生成器完整执行后再返回退出码，默认数据库名对齐 `madong`，交互判断对齐 `isInteractive()`，非交互模式明确提示默认值，安装成功提示手动重启与后续单独构建。

### 回归测试

- 新增 `tests/security/`、`tests/integration/`、`tests/support/` 回归用例与脚手架，覆盖导出路径守卫、密钥 fail-fast 与伪造令牌、后台身份复核、安装流程守门；`phpunit.xml` 移除失效的 `tests/portal` 引用，`.gitignore` 放行回归用例。
- **PHP 8.2.33 / PHPUnit 10.5.0：60 个用例、106 个断言全部通过**，全部改动 PHP 文件通过 `php -l`。

## ⚠️ 升级提示

1. **先备份** `.env` 与 `config/database.php`。
2. **存量部署必须先配置密钥**：执行 `php webman jwt:secret` 生成 `JWT_SECRET`，再重启后端。改为 fail-fast 后，密钥缺失、为占位值（如 `change-me-openssl-rand-hex-32`）或过短时服务会直接启动失败；生成或轮换后所有已签发的 access / refresh 令牌立即失效，用户需重新登录，请安排维护窗口。`--force` 仅用于主动轮换。
3. **配置变更**：`.env` 模板中的 `JWT_SECRET=` 为空值且置于末尾，`APP_EVENT_LOOP=` 留空；`JWT_SECRET` 禁止提交到仓库。标准版 `config/process.php` 原本即为同步事件循环，无需改动；本版**无数据库迁移**。
4. **构建**：`template/admin`、`template/web` 无需重新构建；如需更新前端资源，可在安装后单独执行，安装流程不再强制构建。
5. **回归验证**：执行 `vendor/bin/phpunit`；重点验证后台登录、`download-excel?file_path=../../.env` 返回「非法的导出文件路径」、合法 `/exports/xxx.xlsx` 正常下载、用公开固定密钥签发的令牌被拒、CLI 与 Web 安装流程。
