## 后端更新（backend/）

### ✨ 消息模板来源隔离与同步命令

消息体系引入**来源（source）字段**，实现框架 / 插件 / 后台自建三类数据的生命周期隔离。

- **数据库迁移** `2026_09_17_000001_add_source_to_message_tables.php`
  - `sys_message_category` / `sys_message_definition` / `sys_message_template` 三表新增 `source varchar(50)`（`system` / `plugin:{name}` / `user`）并加索引
  - `sys_message_template` 新增幂等键 `key`，唯一索引 `uk_msg_template_type_key (type, key)`
- **同步服务** `core/business/message/MessageDataSync.php`
  - 三种模式：`increment`（增量）/ `sync`（智能同步，删除本来源孤儿节点）/ `full`（清空重导）
  - 幂等键：分类 `source+key`、定义 `category_id+key`、模板 `type+key`
  - `purge()` 按来源清理，模板仅在无 `DefinitionRel` 引用时才删除（保护全局共享模板）
- **CLI 命令** `php webman madong:migrate-message [plugin] [--all] [--sync] [--full]`
  - 未指定插件时同步框架（source=system）；`--all` 覆盖框架与全部插件
- **插件安装 / 卸载集成**（`PluginInstall`）
  - 安装：自动从 `resource/data/message/category.php` 导入插件消息（智能同步）
  - 卸载：按 `source=plugin:{name}` 清理分类 / 定义 / 模板关联，**表结构与用户数据保留**
  - 后台手工创建的消息固定写入 `source=user`，不受任何同步 / 清理影响
- **数据文件规范**：`resource/data/message/category.php` 单文件合并定义（分类 > 定义 > 模板嵌套）

### 📁 插件资源目录归位 data/menu

插件资源目录从扁平 `resource/menu/`、`resource/message/` 统一归位到 `resource/data/*`：

- `resource.*` 配置默认值调整：`menu → data/menu`、新增 `message → data/message`
- `MigratePluginMenuCommand` 菜单目录支持从插件 `config/info.php` 的 `resource.menu` 读取，不再硬编码
- 脚手架（`PluginDevelopService`）目录模板补充 `resource/data/message`、`resource/data/dict`

### 🔐 权限与菜单体系对齐

- 补全框架菜单权限码并统一 `app` 字段为 `admin`，接口权限注解与权限码三方对齐
- 接口分类树按模块归类并支持插件分组
- MCP 权限目录归属与类型调整（最终为按钮权限）
- 修复：权限扫描在 `base_path` 为 `/app` 时类名解析错误、菜单角色服务权限缓存清理引用错误类名、菜单同步换父重复插入及误删插件菜单、插件菜单同步 `app` 字段校正、插件图标缺少 data URL 前缀破图

### 📦 工作流引擎依赖化

- 工作流引擎从源码集成切换为 **composer VCS 依赖 `madong/workflow`**，并放宽版本约束

### 🎮 演示拦截

- 演示拦截支持按路由指定方法、`PLAYGROUND_ENABLE` 环境变量控制（默认关闭）

### 🔧 其他修复

- 插件卸载模板目录删除失败时重试并降级为警告
- admin SPA 路由文件未命中时回退 `index.html`（子目录部署适配）

### 📶 补充变更（2026-09-18 ~ 2026-10-09，随标签一并覆盖）

**上传与云存储（backend）**
- 云存储驱动：私有读签名与对象 key 归一化、文件删除能力、对象存在检查与列举、上传迁移命令重构为云厂商无关通用实现
- 上传记录新增 `source` 归属并按来源精确回收；新增上传残留资源清理命令与插件卸载回收；新增七牛存量附件迁移命令
- 上传运行时信息补充私有空间与存储根目录字段；资源完整地址按当前存储平台解析域名；新增资源访问地址批量换取接口并登记权限码
- 附件管理：密码确认删除与归属子目录、去重补平台与存储空间维度

**会员与菜单（backend）**
- 会员头像上传改走系统内置上传组件；会员活跃判定改为心跳机制节流更新 `last_active_time`
- web 菜单枚举补齐 HEADER 分类与颜色标识；站点菜单验证补齐 code 与公开登录字段校验；菜单同步命令支持跨层级调整识别为更新

**框架与依赖（backend）**
- 新增 `dompdf/dompdf 3.0` 依赖；补齐 core 调度器项目级配置
- 合并三个框架增量迁移为统一升级迁移；移除 workflow 插件残留迁移；精简升级迁移文件头注释

**修复（backend）**
- 业务异常统一返回 HTTP 200 与业务错误码，不再回显请求上下文
- 修复邮件配置读取与忘记密码验证码链路、JSON 编码非法 UTF-8 报错与业务失败码为 0、操作日志记录异常影响业务响应

**插件命令（backend）**
- 插件迁移命令新增 `resource` 场景回写前端模板

**前端（template/admin，09-18 ~ 10-09）**
- 上传与私有空间：云端/私有图片回显补全、头像云存储地址回显、上传设置四驱动私有空间开关、私有空间资源地址换取与签名回填、附件管理上传/详情预览/密码删除
- 站点菜单管理对齐后端模型与字典渲染、补充 code 与公开登录字段展示
- 组件与交互：新增 ReposEditor 仓库入口编辑器、操作栏无权限禁用展示与平铺按钮上限收纳、修复弹窗宽度未应用内容区域、crud 工具栏全屏与列设置文案、日期工具支持秒级时间戳、base 接口 remove 兼容对象入参
- 修复：非超管不挂载终端弹窗、二进制响应直接放行、路由解析支持插件 module/views 组件路径、开发代理新增 /api 转发

## 升级提示

1. **后端**：`git pull` → `composer update`（工作流引擎已切换 VCS 依赖）→ `php webman phinx migrate`（消息 source/key 迁移）→ 可选执行 `php webman madong:migrate-message --all` 补齐消息数据 → 重启 Webman 进程
