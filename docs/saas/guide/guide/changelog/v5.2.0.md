# v5.2.0 更新日志

> 发布日期：2026-09-29

本文记录 v5.2.0 的变更。升级前请先阅读[升级指南](./upgrade.md)。

---

## 🤖 MCP 端点接入（核心新增）

### 新增能力

- 新增 `core/communication/mcp` 能力域：`/mcp` HTTP 端点，含 API Key 认证、Redis 会话存储、PSR-7 桥接与响应发射器
- 新增 `#[McpTool]` 注解驱动的工具发现与清单（`ToolManifest`），内置 20+ 工具覆盖运维（缓存/队列/健康检查/服务器监控）、系统（配置/账号/当前用户）、目录（字典/菜单/插件）、开发（代码检索/库表结构/日志/路由）与 CI（DB 查询/任务触发）
- 租户隔离双模式：新增 `McpTenant` 统一入口，平台级语义保持不过滤、租户级自动切库；`APP_TENANT_ENABLED=false` 切换单体模式时全部走 no-op/默认连接
- `DbQueryTool` 增加字段隔离守卫，已绑定租户时拒绝查询租户表
- 新增 `madong-mcp:serve`（STDIO 传输，供 MCP Inspector 本地调试）、`madong-mcp:list`、`madong-mcp:call` 命令
- 新增 `config/mcp.php` 配置文件；`/mcp` 端点路由在默认路由关闭前注册，不挂常用中间件分组

### 升级影响

- 新增 composer 依赖：`mcp/sdk 0.8`、`nyholm/psr7 1.8`、`symfony/finder 7.3`
- Windows 控制台无稳定阻塞 STDIN，STDIO 调试建议 Linux/macOS 或改用 HTTP 端点

## 🔔 菜单徽标推送（核心新增）

### 新增能力

- 菜单下发契约扩展：根级新增 `badge` / `badge_type` / `badge_variants`（snake_case），配置来源于菜单 `variable` 根级 `badge` 域，未配置则不下发任何徽标字段
- 新增菜单徽标装饰事件 `adminapi.menu.badge_decorate` / `platform.menu.badge_decorate`，业务监听器可为菜单追加/覆盖徽标；内置示例监听器
- 新增 `MenuBadgePushService` 基于 webman/push 的实时推送，附带 `MenuBadgePushCommand` / `MenuBadgeSetCommand` 推送与设置命令
- 前端 admin / platform 双端接入：Push 客户端（`utils/push/client`）、徽标提取（`utils/menu-badge`）、实时写回（`menu-badge-applier`）、路由守卫初始化与登出销毁

### 问题修复

- 修复 webman/push 进程配置读取：项目级 `config/plugin.php` 会遮蔽 `plugin.*` 目录命名空间导致 `config()` 提前读取返回 null，改为直接读取同级 `app.php`

## 🔐 租户编码登录

- 登录接口新增 `tenant_code` 参数（`tenant_id` 保留兼容），后台按 `findByCode()` + `isActive()` 优先解析租户
- admin 登录页新增租户搜索组件：远程关键词搜索、展示租户名称提交租户编码、支持列表外编码自由输入、编码-名称映射缓存

## 📁 上传存储空间隔离

### 新增能力

- 上传表新增 `space` 字段区分公开/私有空间；平台端使用公开桶、管理端使用私有桶
- 新增 `StorageUrl` 统一资源地址换取：公开空间拼 CDN 地址、私有空间换签名直链；`fullUrl` 支持签名直链
- Local / OSS / COS / 七牛 / S3 存储驱动全面适配空间隔离；Local 在 Windows 跨盘移动改用 copy + unlink 回退
- 文件管理新增详情页与上传页；头像、图片选择器、上传扩展抽屉接入签名直链

### 优化重构

- 平台端新增文件管理 API 封装；站点 Logo / 用户头像等资源 key 统一经 `buildStaticUrl` 解析，修复公开空间 Logo 被当同域资源请求导致 404 的问题

## 📋 菜单与消息

- 菜单模板与租户菜单同步支持 `is_tab`（显示标签页开关），菜单下发 `is_tab=0` 转换为 `meta.hideInTab`
- 菜单模板同步按白名单过滤字段，防止意外字段（如 id）写入；前后端表单字段名统一 snake_case
- 消息中心模型新增来源（source）字段，安装流程集成消息初始化
- admin 端菜单下发接入徽标装饰事件，菜单格式化监听器同步重构

## 🏗 基础设施

- 支持 Swow 协程事件循环：`eventLoop` 改由 `.env` 的 `APP_EVENT_LOOP` 配置（默认 Swow，未安装扩展置空回退同步模式）
- `CacheService` 构造器零 IO，连接/适配器延迟到首次使用，并按 `support\Context` 协程隔离，修复 Swow 并发下的循环依赖与共享连接读错误
- `BaseModel` 对含 `tenant_id` 列的表无条件强制覆盖租户标识，防止租户数据篡改
- `Crud` 控制器 ID 参数规范化校验：拒绝数组/对象、字符集白名单、主键类型转换与存在性校验
- 站点配置登录态差异化：未登录拉取平台配置、登录后 `syncTenantPreferences()` 同步租户配置；`/auth/site-info` 加入租户头豁免列表
- 杂项：表格操作列确认回调修复（`options.ok`）、定时任务页 `ActionItem` 类型修正、日志页表单 `triggerFields` 修复等

## 📦 数据库迁移

- 新增 `2026_09_27_000001_add_source_to_message_tables.php`：消息表增加来源字段
- 新增 `2026_09_27_000002_add_space_to_upload_table.php`：上传表增加空间字段
- 新增 `2026_09_28_000001_add_is_tab_to_menu_tables.php`：菜单相关表增加 `is_tab` 字段

### 升级提示

- 需执行 `php phinx migrate` 完成表结构变更
- 需执行 `composer update` 安装 MCP 相关依赖
- 需重新构建 admin / platform 前端并同步 `public/platform` 构建产物
- 需重启服务加载进程与配置变更；使用菜单徽标推送需配置 WSS（`VITE_GLOB_ENABLE_WSS` / `VITE_GLOB_WSS_URL` / `VITE_GLOB_WSS_APPKEY`）
- 可选：`.env` 配置 `APP_EVENT_LOOP` 启用 Swow 协程（未安装 swow 扩展请置空回退同步模式）
