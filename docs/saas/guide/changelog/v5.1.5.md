# v5.1.5 更新日志

> 发布日期：2026-11-05

本文记录 v5.1.5 的变更。升级前请先阅读[升级指南](./upgrade.md)。

> **版本说明**：本产品由多个仓库组成，各仓库独立发版，版本号未来不一定同步；本次发布各仓库版本统一定义为 5.1.5。变更按仓库归类，仓库内再按平台端、后台端等使用端细分。

| 仓库 | 本次版本 | 对应端 |
|---|---|---|
| backend | 5.1.5 | 平台端 `platform` / 后台端 `admin` / 前台 API `api` / 安装服务与命令行 |
| template/mono | 5.1.4 | 平台端 `platform`、后台端 `admin`、安装向导 `install` |
| template/web | 5.1.4 | 前台站点 `web` |

---

## 🧩 backend（后端服务）

本版主要调整集中在此仓库，按端与能力域分述如下。

### 平台端（platform）接口与鉴权

- 修复应用中间件组 key 误写为路由前缀 `platformapi` 导致不生效的问题：改为应用名 `platform` 并组级挂载 `AccessTokenMiddleware`，避免逐控制器遗漏，修复租户管理接口未鉴权。
- `AccessTokenMiddleware` 无条件校验管理员类型（`platform` / `root`），缺少即返回 403，不再受 `tenant.enable` 影响，修复多租户模式下租户 Token 可访问平台管理端的问题；兼容平台登录写入的 `types` 与租户登录写入的 `admin_types`，并支持字符串、对象两种结构。
- 平台端身份判定改用已验证的 JWT 载荷（叠加黑名单、令牌类型、用户标识与服务端 JTI 注册复核），不再直接信任请求载荷中的管理员类型声明。
- 批量清理平台控制器上重复的鉴权中间件注解及失效引入，鉴权统一由应用级中间件承担；定时任务与日志控制器保留 `OperationMiddleware`。
- 队列管理接口的导出文件下载与删除接入路径守卫，队列消息改为字段白名单（仅传递已校验的相对文件名），修复路径遍历风险。
- 平台端管理员校验允许编辑安装期创建的既有 `root` 账号，仍禁止新建账号或将其他账号改名为 `root`；唯一性校验绕过 `TenantScope` 保持全局有效。
- 平台远程安装插件仅上架插件、不写入平台消息数据；远程与租户安装完成后按租户同步插件消息数据，卸载时按租户清理；安装运行态记录按 `tenant_id + plugin_key` 幂等写入，避免孤儿记录触发唯一键冲突。

### 后台端（admin / adminapi）接口

- 消息分类、定义与模板读侧合并 `tenant_id=0` 平台默认数据与当前租户数据，租户行优先；控制器注入 `currentTenantId`，平台与单租户模式只读取平台默认数据。
- 消息推送时模板与定义查询避免 `TenantScope` 污染，租户环境下可正确命中模板。
- 下载导出 Excel 接口改用 `UploadDownloadExcelRequest` 请求 DTO 校验，并接入导出路径守卫，修复下载接口的路径遍历风险。
- 后台端管理员校验允许编辑安装期创建的既有 `root` 账号，仍禁止新建账号或将其他账号改名为 `root`。

### 安装服务与命令行（install / CLI）

- CLI 安装交互顺序调整为「环境检测 → 数据库 → 是否启用多租户 → 超级管理员账户 → 安装选项」，与 Web 向导一致；密码输入改为按行读取，消除 STDIN 残留造成的问题被跳过与答案错位。
- 多租户默认使用平台超管 `root`，单租户默认 `admin`，默认库名对齐 `madong_saas`。
- 前端构建默认关闭且失败不阻断安装，修正安装锁与 `.env` 写入顺序及 CLI 退出码。
- 安装流程自动生成随机 `JWT_SECRET` 并写入 `.env`，重装时保留已存在的合法密钥；`.env` / `.example.env` 模板补齐 `JWT_SECRET` 与 `APP_EVENT_LOOP` 空值说明，未安装 swow 扩展时按同步模式启动。

### 后端公共能力（各端共用）

#### 认证与文件安全

- `core/security/config/jwt.php` 不再提供示例默认密钥，`JwtToken` 构造时对缺失、占位值或短于 32 字符的 `JWT_SECRET` 直接 fail-fast，不再回退公开的固定密钥。
- 新增 `core/security/jwt/JwtSecret` 作为密钥生成与校验唯一入口：256 bit 随机密钥、强度校验与 `.env` 幂等写入；新增 `php webman jwt:secret` 命令用于存量部署生成或轮换密钥（`--force` 强制轮换），密钥明文不输出。
- 新增 `JwtToken::getVerifiedPayload()`，在签名与过期校验之外叠加黑名单 JTI、令牌类型、用户标识与 Redis 中 JTI 注册复核。
- 新增 `core/io/excel/ExportPathGuard`：统一校验导出目录白名单（`runtime/exports/`）、`realpath()` 规范化与根前缀比较、扩展名与文件存在性，并过滤下载响应名与磁盘文件名中的路径符、CRLF、`..` 及会污染 URL 查询串的字符；`ExcelExportService` 与 `RemoveExcelFile` 队列消费者各自接入守卫，队列消息使用字段白名单。

#### 多租户消息与插件链路

- 新增 `TenantMessageSyncService`，按租户隔离模式（field / database）解析目标连接，驱动插件安装后的消息同步与卸载清理。
- `MessageDataSync` 显式传入 `tenantId` / `connection`，库隔离租户数据写入目标库；幂等查询绕过 `TenantScope` 并按 `tenant_id + source + key` 匹配；写入改用查询构造器，避免 `BaseModel` 的 `creating` 钩子覆盖 `tenant_id`；卸载按 `tenant_id + source` 精准清理，跨来源 key 冲突告警跳过。
- 插件安装 / 卸载链路显式透传 `setContext`、`setTenantId`、`setConnection`，按租户 `database_mode` 解析连接，不再依赖请求态上下文；编排器改用 `setTenant` 并快照恢复隔离模式。
- `TenantMigrationService` 补绑定库隔离连接，避免迁移与种子数据落到主库。
- `plugin/demo` 新增 `demo_notice` 分类、`demo_notice_push` 定义与 `demo_notice_tpl` 模板，标记 `source=plugin:demo`，作为多租户消息同步示例。

#### 数据库迁移与运行时配置

- 新增迁移 `2026_11_04_000001_scope_message_tables_by_tenant.php`：`sys_message_category` / `sys_message_definition` / `sys_message_template` 的唯一索引由单列 `key` 改为含 `tenant_id` 的组合键（`uk_tenant_key` / `uk_tenant_category_definition` / `uk_tenant_type_key`），解决租户安装插件写入消息数据时的 `Duplicate entry ... for key 'uk_key'` 冲突。
- 历史 `tenant_id = NULL` 归一为 `0`（平台 / 单租户默认数据）并置为 `NOT NULL DEFAULT 0`；按新唯一键去重（优先保留 `source=system`），同步清理 `sys_message_definition_template` 中的关联；兼容旧表不存在 `source` 列的情况。
- 中间件配置统一为全路径类写法，规避同名类歧义；`config/process.php` 改由 `extension_loaded('swow')` 决定事件循环，未安装 swow 扩展时自动回退同步模式。

### 回归测试

- 新增安全与安装流程回归用例及测试脚手架，覆盖密钥生成与 fail-fast、平台端身份复核、导出路径守卫、安装器锁顺序 / 构建降级 / 租户开关 / 账号默认值。

## 🖥 template/mono（前端大仓）

### 平台端（platform）

- 本版无前端代码改动；平台端鉴权、队列接口与远程安装相关调整均位于 `backend`（见上文「平台端接口与鉴权」）。

### 后台端（admin）

- 本版无前端代码改动；消息中心与导出下载相关调整位于 `backend` 接口层（见上文「后台端接口」）。

## 🌐 template/web（前台站点）

- 本版无功能变更，沿用 v5.1.4，站点资源无需重新构建。

## 📝 文档

- 安全开发规范同步补充：JWT 随机密钥与 fail-fast、密钥 / token 不落日志、平台端身份复核、`filterWord` 仅作辅助过滤而非路径安全边界，并新增「文件下载与导出」路径校验规范。

## ⚠️ 升级提示

1. **先备份数据库与 `.env`**：执行 `php phinx migrate` 应用 `2026_11_04_000001_scope_message_tables_by_tenant.php`；迁移含 `tenant_id` 归一与历史数据去重，`down()` 只回滚索引结构、数据变更不可逆。
2. **存量部署必须先配置密钥**：执行 `php webman jwt:secret` 生成 `JWT_SECRET`，再 `php webman restart`。密钥缺失、占位值或过短时服务会直接启动失败；生成或轮换后所有已签发的 access / refresh 令牌失效，用户需重新登录，请安排维护窗口。`--force` 仅用于主动轮换。
3. **合并中间件配置**：自定义过 `config/middleware.php` 的部署需合并 `platform` 应用组（含 `AccessTokenMiddleware`），否则平台端接口仍处于未鉴权状态；控制器上重复的鉴权注解可一并清理。
4. **环境与构建**：`.env` 中未安装 swow 扩展时 `APP_EVENT_LOOP` 留空；`JWT_SECRET` 禁止提交到仓库。重新构建安装向导前端 `pnpm build -F @madong/install`，平台端、后台端与前台站点本版无需重新构建。
5. **回归验证**：执行 `vendor/bin/phpunit`，并重点验证平台端登录鉴权、Excel 导出下载与清理、租户插件安装后的消息数据可见性、CLI / Web 安装流程。
