## 🚀 菜单应用选择体系（核心）

> 涉及仓库：backend、template/mono（admin）

### 新增能力

- 菜单模块应用列表（`/system/menu/app/list`）支持按部署模式自动取数：单体模式读取平台插件注册表 `sys_plugin`，租户模式读取租户安装运行态表 `saas_tenant_plugin_install`，插件安装/卸载后下拉选项自动增减
- 应用列表新增 `end` 端别参数（`admin`=后台，默认 / `web`=前台），「系统应用」选项值随端别切换（后台 `admin` / 前台 `web`），与 `sys_menu` / `web_menu` 预置数据语义对齐
- 应用下拉由已安装插件自动驱动，不再依赖字典或硬编码应用清单
- 新增表单 switch 组件（`form/components/switch`）

### 问题修复

- 修复菜单 schema 中 `requestMethod` 大小写不匹配（`'GET'` → `'get'`）导致 `requestClient` 方法索引失败、应用下拉静默为空的问题（系统菜单与站点菜单搜索表单及表单抽屉共 3 处）
- 表单下拉组件由 `ElSelectV2` 调整为 `ElSelect`，修复其在抽屉内因虚拟列表 `clientHeight=0` 塌陷导致选项不渲染的问题
- 修复平台菜单列表、菜单模板列表未解析搜索条件的问题

## 🔍 CRUD 刷新携带搜索条件

> 涉及仓库：template/mono（admin、platform）

- admin / platform CRUD 表格工具栏刷新支持携带当前搜索条件，刷新后不再丢失生效条件
- vxe 表格工具栏刷新携带当前搜索条件，搜索表单未挂载时回退最近提交值，保持原有行为

## 🏛 站点配置与门户

> 涉及仓库：backend、template/mono（admin、platform）

### 新增能力

- 新增后台站点配置管理接口（`/web/site-config`）
- admin 新增站点设置页面，拆分站点信息、页脚、统计代码三个子组件（`site-config/components/`），语言包同步更新
- 新增前台门户导航配置与友链申请接口

### 问题修复

- platform 品牌配置取值新增 `getBrandConfig` 统一逻辑：租户仅配置 Logo 未配置站点名时不再被平台配置整体覆盖，favicon 未单独配置时回退 Logo，并增加去重设置避免两端配置反复切换
- 修复系统配置读取顺序不稳定与重复插入的问题
- 站点配置接口异常捕获由 `\Exception` 放宽为 `\Throwable`
- 站点菜单模型枚举字段（`category` / `type` / `target` / `is_show` / `enabled`）统一整型转换，避免与字典项类型不一致
- 前台菜单删除接口兼容单条（`DELETE /web/menu/{id}`）与批量（`ids`）两种调用，新增 `batchDelete`

### 优化重构

- admin 站点菜单类型定义重写：雪花 ID 以字符串表达避免 JS 精度丢失，字段（`category` / `app` / `type` 等）与后端模型对齐
